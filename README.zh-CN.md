## 为什么是它

**它给你的是一个决定，不是一次确认。** 当它想跑一条命令或者动一个文件时，你看到的是：
它打算做什么、动哪些文件、连哪个网络地址、这次授权持续多久。高亮默认停在 _No_，
你转身走开也等于拒绝。

**它不夸大自己在保护你什么。** 大多数 agent 会说"已沙箱"。这一个在启动时和 `/status` 里
按维度逐条打印强制级别 —— 并且拒绝把任何只是策略的东西说成"已强制"。
如果在你的环境里子进程的网络拦截只是尽力而为，它会在你敲第一个字之前就讲清楚。

**它就是一个进程，没别的。** 零运行时依赖。Node 22.18+，供应链到此为止。

## 安装

```bash
npm install -g ./mycoder-0.1.0.tgz
mycoder doctor
```

`doctor` 只会得出两个结论之一，不会有第三个：**就绪**，或者**被挡住** ——
并且指明要创建哪个文件、要设哪个 key、怎么验证它生效了。它不建立会话，也不写任何东西，
因为它正是 `mycoder` 起不来时你会去敲的那条命令。

## 接上一个模型

MyCoder 支持 Anthropic、OpenAI，以及任何讲 OpenAI 兼容 Chat 协议的服务
（DeepSeek、Together、OpenRouter、本地的 llama.cpp）。把 key 放在一个内核读得到、
别人读不到的地方：

```bash
printf %s "$YOUR_API_KEY" | mycoder setup-credential ~/.config/mycoder/secrets/deepseek.key
```

它只从 stdin 读，拒绝从终端读 —— 所以你的 key 不会被回显到屏幕上；文件权限它自己会设好。

然后在 `~/.config/mycoder/config.toml` 里点名这个 provider：

```toml
[model.provider.deepseek]
protocol     = "openai-chat"
base_url     = "https://api.deepseek.com"
api_key_file = "secrets/deepseek.key"

[model.alias.deepseek]
provider = "deepseek"
model    = "deepseek-chat"

[model]
default = "deepseek"
```

`docs/configuring-a-provider.md` 里有一份可以照抄的例子、每个字段的说明，
以及本地模型的写法；如果哪一行写错了，`mycoder doctor` 会点名那一行。

## 怎么用

在你要动的项目里跑 `mycoder`。它开场先说清这次会话的底细 —— 用哪个模型、
有多少上下文、生效的是哪个权限档、动手前会不会问你，以及隔离级别到底是什么。

<img src="docs/media/banner-zh.png" width="820" alt="启动横幅：模型、上下文窗口、权限档、审批模式、隔离级别和工作目录，右侧一列提示，下方是输入框，框里是一行中文任务。">

然后把你想要的事情打进去。普通句子，没有什么提示词格式要学。

| 输入时              |                                               |
| ------------------- | --------------------------------------------- |
| `@src/thing.ts`     | 附带一个文件 —— Tab 可以补全                  |
| `/`                 | 控制命令 —— 同样能 Tab 补全，`/help` 列出全部 |
| `!npm test`         | 只显示这条命令会被怎么解析，不真的跑          |
| **Shift-Tab**       | 切换"哪些事可以不问就做"                      |
| **Ctrl-C / Ctrl-D** | 取消这一轮 / 退出                             |

**看着它干活。** 每次工具调用一行，每个结果一行。并行调用多个工具时，
每个结果都会标出属于哪次调用 —— 它们是按完成顺序回来的。

<img src="docs/media/tools.png" width="820" alt="进行中的一轮：并行的 Read 调用，每行结果都标出对应的文件和大小。">

**回答它的提问。** 方向键选，或者直接敲编号。

<img src="docs/media/approval.png" width="820" alt="审批提示：一个方框列出工具、动作、命令、目录、网络和授权范围，下方四个带编号的选项，高亮停在 No 上。">

如果你不想每次编辑都被问一遍，**Shift-Tab** 在
`plan` → `manual` → `accept-edits` → `auto` 之间循环。`accept-edits` 会直接应用工作区内的编辑，
其他事情照问不误；`plan` 则什么都改不了。任何模式都不能放行权限档已经拒绝的事 ——
凭据、网络、git 历史和外部工具，在每一种模式下都会问。

**看它到底做了什么。** 一轮结束时给出实际发生的事，数字来自事件本身而不是模型的自述 ——
被拒绝的部分单独列出。

<img src="docs/media/turn.png" width="820" alt="一轮的结尾：读了几个文件、列了几个目录、写了几个文件，然后是模型、上下文窗口、请求数、token 数和花费的状态行。">

### 会话之间

```bash
mycoder -c                        # 接着这个项目最近一次会话
mycoder -r                        # 从最近的会话里挑，按"当时让它做什么"列出
mycoder "fix the failing test"    # 一个任务，做完退出
mycoder --json "…"                # 一行一个 JSON 对象，给脚本用
mycoder --read-only "…"           # 只许看，不许动
```

### 它做错了的时候

`/undo` 撤销上一次编辑、上一轮的编辑，或者某个文件的编辑 —— 恢复到完全相同的字节。
文件在那之后被改过时它宁可拒绝也不猜；一组编辑要么全撤要么一个不撤；
并且会告诉你它**没有**覆盖到什么：shell 命令的副作用，以及会话开始之前的一切。

## 它能做什么

**九个核心工具：** `Read`、`Grep`、`Glob`、`Edit`、`Write`、`Delete`、`Move`、
`Shell`、`GitDiff` —— 全部走同一套契约，把"一个工具想做什么"和"真的去做"分开，
所以权限是在任何事情发生之前就决定好的。删除会在普通写入不问的地方发问。
`WebFetch` 只有当你点名了它可以访问的主机时才会出现。

**它不能编辑一个自己没读过的文件。** 每次编辑都必须引用那次让模型看到该区域的读取，
所以针对已经变动的内容做的编辑会被拒绝，而不是悄悄改到错误的行上。

**写入是原子的**，带 unified diff、回滚元数据，并保持你原来的行尾。

**密钥被当作密钥对待。** 存放密钥的路径直接拒绝，工具输出在送给模型之前会被扫描，
key 存在一个 broker 里 —— 它的租约没法靠打印变回原值。

**所有出站字节走同一道闸**，每个通道各有自己的主机白名单。遥测只走元数据，
`--no-telemetry` 可以整个关掉。

**长任务有边界。** `/loop` 给一轮设定步数、时间和花费预算；上下文不够时 `/compact`
会把较早的对话压缩掉；`/status` 显示已经花了多少。

**它可以跑在别处。** `--remote` 把工具执行放到 SSH 远端；`--backend container`
把命令跑在容器里，你的 home 和凭据目录是**根本不存在**而不是被拒绝。

**它可以被仓库扩展** —— 从项目里发现 skills、子 agent 和 hooks ——
规则是：一份定义只能收窄权限，永远不能放宽。

## 你在信任什么

启动横幅存在的全部意义，就是让这一节对你来说不是意外。

在**本地**和 **SSH** 后端上，MyCoder 是 `policy-enforced`，**不是** `os-isolated`。
内核决定工具能请求什么、并对它们返回的东西做脱敏，但一条跑起来的命令就是一个普通进程，
带着你的用户权限：它碰得到文件系统，而"网络已关闭"是尽力而为 ——
没有任何东西会去检查一条命令是否用到网络，所以一条真的连了外网的命令
既没有被批准也没有被拒绝，它就是跑通了。

`--backend container` 为命令改变了这一点，也只为命令。它们跑在只读根文件系统上，
capabilities 全部丢弃，`no-new-privileges`，没有授权就没有网络，
你的 home 和凭据目录是从容器里缺席，而不是在容器里被拒绝。
读文件和改文件仍然由内核在你真实的文件系统上完成，也仍然如实报告为
`policy-enforced` —— 因为事实就是如此。

`docs/threat-model.md` 是完整版，包括「一个控制了你指给它的那个仓库的攻击者」
能做什么、不能做什么。

## 这一版没有的东西

没有 MCP 市场、agent 团队、IDE 插件、浏览器操作、embedding 或仓库地图、
模型路由、云同步、后台守护进程。每一个都留了以后接上去的位置；
现在没有一个是做了一半横在路中间的。

## 出问题的时候

先跑 `mycoder doctor` —— 它就是为这一刻写的。

退出码是一份契约，不是装饰。**1** 是模型没做完 —— 放弃了、撞上预算、或者被取消；
**3** 是你的配置；**4** 是策略拒绝了某件事；**5** 是你的机器；**6** 是 MyCoder 自己的 bug。
没有任何一个大于 6，因为 `127` 和 `>=128` 是 shell 的地盘。一个包装脚本不需要读英文
就能区分它们；`docs/cli-contract.md` 列出了全部，并承诺它们在 `0.1.x` 之内不会变。
